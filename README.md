# Calculadora de Operações

## Sobre o projeto

A Calculadora de Operações é um projeto desenvolvido para praticar os fundamentos do desenvolvimento web utilizando HTML, CSS e JavaScript.

A aplicação permite informar dois valores numéricos e realizar as quatro operações matemáticas básicas.

## Funcionalidades

- Adição.
- Subtração.
- Multiplicação.
- Divisão.

## Tecnologias utilizadas

- **HTML5:** estrutura da página.
- **CSS3:** apresentação visual e estilização dos elementos.
- **JavaScript:** lógica de cálculo e interação com o usuário.

## Como utilizar

1. Acesse o site pelo link abaixo.
2. Informe o primeiro valor numérico.
3. Informe o segundo valor numérico.
4. Clique no botão **Calcular**.
5. Consulte o resultado apresentado na página.

## Como executar localmente

1. Baixe ou clone os arquivos deste repositório.
2. Mantenha os arquivos `index.html`, `style.css` e `script.js` na estrutura esperada pelo projeto.
3. Abra o arquivo `index.html` em um navegador compatível.

## Objetivo de aprendizagem

Este projeto faz parte da minha prática de desenvolvimento de software e tem como objetivo exercitar a criação de interfaces web, a lógica de programação em JavaScript, o controle de versão com Git e GitHub e a publicação de aplicações na internet.
